HOW TO PLAY

OBJECTIVE

Clear all breakable bricks to advance to the next level. Penetrate dense corridors to trigger rapid satisfying chute ricochets!

Levels 6–10 are built for bot challenges: titanium armor, staggered vaults, tight gates, and multiball ricochets.

BRICK TYPES

Amber: Regular (1 Hit)
Orange: Reinforced (2 Hits)
Crimson: Titanium (3 Hits)
Slate: Chute Wall (Indestructible)
Cyan: Speed Booster (+15%)
Purple: Bomb (3x3 Blast Radius)
Lime ×2: Double active balls
Pink +3: Add 3 balls
Blue Shield: Energy floor for 9s

Break a ×2 or +3 brick to activate it instantly, including with a bomb. Up to 32 balls can be active at once. A life is lost only when every ball is gone.

Bombs caught in a blast detonate a beat later, so touching bombs roll across the field as a chain reaction. When only a few bricks remain, balls turn pink and hunt them down.

RANDOM MAPS [N]

Pick 🎲 Random in the level menu or press [N] for an endless run of generated maps: new patterns, walls, and colors every time, never repeating on this device. Each map shows its seed; the address bar keeps ?seed= so the same run can be replayed. Add &bot=1 to start with the AI bot.

AUTONOMOUS BOT [B]

Toggle the autonomous bot player at any time with the [B] key or AI BOT button. The bot predicts trajectories and prioritizes the descending ball closest to the paddle. Multiball challenges can send balls to opposite sides at once, so the bot may drop some.
